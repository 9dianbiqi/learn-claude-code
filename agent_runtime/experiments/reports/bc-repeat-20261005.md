## 行为解释与限制

标记事件按运行前冻结的规则统计：包含标记但不独占一行归为格式错误；没有任何标记的文本回复仅是候选缺失，不推断模型意图。文件复核不自动判为浪费或副作用重复。

补充描述性分析：按轨迹辨认“写入后再次读取同一文件”（预设重复读取类别的事后细分），以及 integration verifier 的失败次数。
- B：写后复读 1 次；验收失败 0 次。
- C：写后复读 6 次；验收失败 0 次。

只有两个独立任务和两份前缀快照；20 次续跑不能视为 20 个独立任务。没有本轮无中断对照，不能声称长程任务上的总体优势或非劣性。最终验收复用子任务断言，不是额外隐藏覆盖。恢复后 token 包含剩余编码，不能称为纯恢复开销。
